## 新电脑需要什么

| 目标 | 必需文件 | 不需要先做 |
| --- | --- | --- |
| 单图推理 | Git 代码、Python 环境、一份道路检测 PT、一张道路图 | 全量数据、训练、旧 runs |

## 环境与最小命令

从项目根目录运行，推荐 Python 3.10/3.11。新电脑创建独立虚拟环境并安装 requirements.txt；按目标设备安装可用的 PyTorch，先以 CPU 验证链路。检查 torch、torchvision、ultralytics、opencv-python、numpy、pandas、Pillow 的实际版本及 pip check。不要复制另一台电脑的 .venv；历史 .venv 曾复用全局包；当前已单独创建隔离环境，其他电脑仍需自行安装与实机验收。

```bash
python scripts/predict_image.py --source "path/to/road.jpg" --output ".local/image-01" --device cpu
python demo/demo.py --source "path/to/images-or-video" --output ".local/demo-01.mp4" --device cpu --max-frames 120
```

将 path/to/... 替换为真实输入；输出名称每次换新。单图应生成 prediction.jpg/json；离线演示生成视频和 JSON。图片目录生成图片序列，不是连续行车视频。无框不等于无损坏；本机计时不代表其他设备性能。

## 数据与正式评估

现在可直接从三国 ZIP 按原清单准备数据，避免旧相对路径；使用新目录并保持原划分：

```bash
python scripts/prepare_dataset.py --archives-root "path/to/country-zips" --output .local/datasets/original-split-v1
python scripts/evaluate_baseline.py --model models/baseline_best.pt --data .local/datasets/original-split-v1/source.yaml --split test --output .local/eval-n-01 --device cpu --batch 8 --save-predictions
python scripts/evaluate_domain_shift.py --source-data .local/datasets/original-split-v1/source.yaml --target-data .local/datasets/original-split-v1/country.yaml --output .local/domain-01 --device cpu --batch 8 --save-predictions
```

本机已经完成全量转换、两模型完整评估和验证集阈值试验，证据见 planning/11_全量复核与继续实施.md。新数据准备会解码所有图片并检查尺寸/框回投影。原无参数 voc_to_yolo.py 保留旧路径逻辑，应优先使用新入口。

当前统一评估/推理 rect=False、imgsz=640、NMS IoU=0.7、max_det=300；历史复核用 --rect 单独记录。AP 汇总 PR 与固定阈值 TP/FP/FN 分开解释。阈值只能用 val，不能根据 test 再调整；已知相似场景需排除/分组，不能宣称旧集合完全独立。

本机候选阈值 0.10 增加召回也增加背景误报，默认仍为 0.25；不要只把阈值调低就宣布模型训练改进。跨电脑独立验收当前按用户要求暂缓。
